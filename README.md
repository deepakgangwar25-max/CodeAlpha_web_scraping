# CodeAlpha Data Analytics Internship - Task 1: Web Scraping

## Overview
An automated web scraping project developed in Python to extract product catalog data from `books.toscrape.com`.

## Features
- Extracts Book Titles, Prices (GBP), Star Ratings, and Stock Availability.
- Cleans currency symbols and converts star ratings to numeric values.
- Automatically exports the structured output into `books_scraped_data.csv`.

## Tech Stack
- Python
- Requests
- BeautifulSoup4
- Pandas
